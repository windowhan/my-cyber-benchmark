# CORE-2010-0121 — Vulnerabilities with Windows 8.3 filename pseudonyms

- **Severity (nginx):** major
- **CVSS:** n/a (no NVD entry)
- **Vulnerable:** nginx/Windows 0.7.52-0.8.32
- **Fixed (not vulnerable):** 0.8.33+, 0.7.65+
- **Patched:** yes

## Description

Windows 8.3 short filename (SFN) pseudonyms can be used to bypass URI-based access restrictions and retrieve protected files on nginx/Windows. External advisory (no CVE assigned). Fixed in 0.8.33 / 0.7.65.
